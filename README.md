CampusCycle

Give Every Item a Second Life.

CampusCycle is a circular economy marketplace designed specifically for college students. It helps students buy, sell, exchange, donate, repair, and upcycle items they no longer need, keeping useful products in circulation and reducing unnecessary campus waste.

Sell • Exchange • Donate • Repair • Upcycle

---

Problem

College students frequently have unused books, electronics, clothes, cycles, furniture, and other supplies.

Existing marketplaces are often too broad and lack a trusted, campus-focused community. As a result, useful products may remain unused or eventually become waste.

CampusCycle creates a student-first circular marketplace where these products can find their next owner.

---

Solution

CampusCycle connects students with other students and local circular-economy partners through one platform.

Students can:

- Buy affordable pre-owned products
- Sell items they no longer need
- Exchange items without using money
- Donate items to students or donation drives
- Repair products instead of replacing them
- Upcycle products into something useful again
- Track their personal environmental impact

---

Key Features

AI Item Analyzer

Upload a photo of an item and receive AI-powered suggestions for:

- Item identification
- Category
- Condition
- Estimated resale value
- Recommended action: Sell, Donate, Repair, or Upcycle

Smart Marketplace

Browse campus listings across categories such as:

- Books
- Electronics
- Clothes
- Cycles
- Furniture
- College Supplies
- Accessories

Item Exchange

Students can propose item-for-item exchanges instead of paying money.

Donation

Donate items directly to students, campus donation drives, or partner organizations.

Repair and Upcycling

Connect students with repairers and upcycling partners so products stay useful for longer.

Circular Score

Students earn Eco Points for sustainable actions and can track:

- Circular Score
- Eco Points
- Items reused
- Items donated
- Items repaired
- Waste prevented
- Money saved

Leaderboard

Encourage sustainable participation through campus-wide rankings and achievement levels.

Campus Ecosystem

CampusCycle connects:

Students ↔ Marketplace ↔ Repairers ↔ Upcyclers ↔ Recyclers ↔ College

Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

Clone the Repository

git clone https://github.com/samiksha0705-code/CampusCycle.git
cd CampusCycle

Install Dependencies

npm install

Configure Environment Variables

Create a ".env.local" file in the project root:

GEMINI_API_KEY=your_api_key_here

Never commit your actual API keys to GitHub.

Start the Development Server

npm run dev

Open the local URL shown in your terminal, usually:

http://localhost:5173
